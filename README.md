# Smart Robot Control Panel

## Project Description
This project is a web-based control panel for a smart robot. It allows users to send movement commands and store them in a MySQL database using PHP.

## Features
- Robot movement control.
- Store commands in a MySQL database.
- Simple web interface.
- PHP backend.

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- InfinityFree

## Installation
1. Create a MySQL database.
2. Import `setup.sql` using phpMyAdmin.
3. Update the database settings in `db.php`.
4. Upload the project files to the hosting server.
5. Open the website in your browser.
